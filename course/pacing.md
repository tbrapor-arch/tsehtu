## Decisions for this course
- **100 lessons.** Every 7th is a review (7, 14, … 98). Plan in `syllabus.yaml`.
- **Second wave from lesson 50:** with lesson N, redo lesson N−49 in active mode (English → Taigi). In the app.
- **Each lesson gets a topic title**, so the list reads like a set of everyday situations.
- **Length:** dialogues start at 8–10 lines and grow to about 15–20 lines in the second half.
- **Density:** the learner has B2 Mandarin, so the second half can be as dense as an advanced-level course.
- **Vocabulary and structures first:** the characters are a backdrop; `make coverage` picks what to teach next.
- **Two short exercises per lesson** (translate, fill the gap).
